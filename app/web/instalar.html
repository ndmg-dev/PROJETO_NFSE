Instalar a ferramenta de teste de certificado

Para computadores Windows. Não precisa digitar comandos nem instalar nada antes.

Este computador não parece ser Windows. A ferramenta usa o repositório de certificados do Windows, então só funciona nele. Abra este mesmo endereço em um computador Windows.

Passo a passo

  1. Clique em Baixar o instalador e abra o arquivo Instalar-Agente-NFSe.bat.
  2. O Windows pode avisar que o arquivo não é comum ou que é desconhecido, porque ele ainda não tem assinatura digital. Clique em Manter no navegador e, se aparecer, em Mais informações → Executar assim mesmo.
  3. Espere. Na primeira vez ele baixa uma cópia do Java (cerca de 200 MB), prepara tudo e cria um atalho na Área de Trabalho.
  4. Na janela que abrir, clique em Ver certificados desta máquina e depois em Testar conexão com um certificado. Envie o resultado para quem administra o sistema.

O que isto faz, e o que ainda não

Sem surpresas:

  • Instala só para o seu usuário, em %LOCALAPPDATA%\nfse-agente. Não pede permissão de administrador.
  • Verifica se o certificado A1 já instalado neste computador pode ser usado sem exportá-lo. Não copia nem envia o certificado para lugar nenhum.
  • É uma versão de validação. O agente completo, que sincroniza as notas, ainda está em desenvolvimento e será instalado por este mesmo link.

Se algo não funcionar

  • O download do Java falhou: a rede do escritório pode estar bloqueando api.adoptium.net ou github.com. Peça a quem cuida da rede para liberar.
  • O antivírus bloqueou o arquivo: ele é um script sem assinatura digital. Peça a quem administra o sistema para liberá-lo.
  • A janela fechou sozinha: abra o atalho Teste de certificado NFS-e na Área de Trabalho.
